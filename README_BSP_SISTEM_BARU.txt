BSP MANAGEMENT SYSTEM - SISTEM BARU
Barokah Sukses Plasindo

PERUBAHAN TERBARU:
1. BOM Produk: Total Berat = Qty/Produk x Berat/Unit Bahan. Stok bahan tidak dikalikan.
2. Nota cetak memiliki tempat tanda tangan Penerima, Pengirim, dan Gudang.
3. Rekap Absensi menampilkan minggu berjalan (Senin-Minggu) secara otomatis. Data lama tetap menjadi histori.
4. Dashboard: Grafik Omzet Harian dan Barang yang Sering Dibeli menggunakan diagram lingkaran.
5. Grafik Barang yang Sering Dibeli dihitung berdasarkan produk, bukan kategori.

CARA MENJALANKAN:
1. Buka CMD.
2. Masuk ke folder BSP-SISTEM-BARU.
3. Jalankan: npm install
4. Jalankan: node server.js
5. Buka http://localhost:3000
